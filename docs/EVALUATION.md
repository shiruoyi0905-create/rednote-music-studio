# AI内容评测方案

## 评测目标

评测不是给作品一个“看起来专业”的总分，而是定位内容在哪个环节不满足发布要求，并生成可执行的下一步修改建议。

## 四个维度

1. **受众匹配**：是否回应目标用户、创作目标和指定关键词。
2. **真实感**：是否包含具体体验，避免泛化、夸张和无法验证的事实。
3. **可读性**：标题与正文长度、结构和语言是否适合移动端阅读。
4. **发布就绪度**：正文、话题和互动结尾是否完整，是否仍需大幅编辑。

## 离线样本设计

- 10条明确歌曲输入；
- 10条仅描述情绪的模糊输入；
- 10条带受众/风格约束的复杂输入；
- 每条至少覆盖2种Brief，共60个生成样本；
- 额外构造事实编造、标题党、禁用词、话题过多等边界样本。

## 人工标注

- 两名标注者独立给四个维度打分；
- 记录是否可直接发布，以及必须修改的问题；
- 分差超过20分时复核并沉淀判例；
- 比较模型评分与人工评分的相关性，而非只看平均分。

## 线上指标

- 首稿采纳率；
- 标题/正文局部重写率；
- 质检建议采纳率；
- 完成导出率；
- 单次任务耗时与满意度。

## 后续迭代

- 用人工标注结果校准评分Prompt和阈值；
- 将Bad Case归因到Brief缺失、生成Prompt、解析或评测标准；
- 增加“一键按建议优化”，但保留人工确认，避免自动覆盖满意内容；
- 当真实样本足够后，再决定是否引入风格记忆或多步骤Agent。
