# Rednote Music Studio

面向小红书音乐创作者的 AI 内容工作台。它把创作任务拆成 **Brief 定义、内容生成、局部重写、AI 质检、视觉封面导出** 五个可检查环节。

## 为什么做

音乐博主常见的困难不是完全没有内容，而是：

- 同一首歌难以针对不同受众形成差异化表达；
- AI 文案容易泛化、标题党或编造歌曲背景；
- 生成后缺少可执行的质量反馈，只能反复“再来一版”；
- 标题、正文和视觉封面分散在多个工具中，发布链路长。

本项目验证：结构化创作 Brief 与生成后评测，能否让 AI 内容更可控、更接近可发布状态。

## 核心体验

1. **定义创作 Brief**：设置目标受众、创作目标、表达风格、必须包含和避免表达。
2. **并行生成**：DeepSeek 并行生成歌曲元信息/5个标题与正文，缩短等待时间。
3. **局部重写**：只重生成标题或正文，保留用户已经认可的部分与上下文。
4. **AI 内容质检**：从受众匹配、真实感、可读性、发布就绪度四个维度评分，输出优势、风险和下一步建议。
5. **可降级体验**：未配置或暂时无法调用模型时，生成使用示例内容，质检自动降级为本地规则评测。
6. **一键出片**：实时预览唱片与声波动效，通过 Canvas 导出 680×920 PNG 封面。

## AI 产品设计亮点

- **结构化上下文**：Prompt 不只接收歌曲名，还携带受众、目标、风格与内容约束。
- **生成与评测解耦**：生成负责创作，质检用低温度独立判断，避免“自己给自己打满分”。
- **结构化输出**：模型以 JSON 返回，服务端负责解析、修复常见格式错误和字段归一。
- **并行与重试**：标题/正文并行请求；失败后顺序重试，兼顾速度与成功率。
- **Human-in-the-loop**：用户保留满意部分、局部重写，并根据质检建议决定下一步。
- **安全边界**：API Key 仅保存在服务端；Prompt 明确禁止编造歌曲背景与艺人经历。

## 评测体系

| 维度 | 关注问题 | 当前实现 |
| --- | --- | --- |
| 受众匹配 | 内容是否回应目标人群与创作目标 | AI语义评测；无Key时检查关键词覆盖 |
| 真实感 | 是否有具体场景、避免空泛与违禁表达 | AI语义评测；本地场景与禁用词规则 |
| 可读性 | 长度、层次和表达是否适合移动端阅读 | AI语义评测；本地长度规则 |
| 发布就绪度 | 话题、互动引导和整体完成度是否充分 | AI语义评测；本地话题与互动规则 |

更完整的指标定义和迭代计划见 [docs/EVALUATION.md](docs/EVALUATION.md)。

## 技术架构

```text
Creator Brief + 歌曲/情绪输入
            │
            ▼
      Next.js Route Handler
       ├─ 标题与元信息生成 ─┐
       └─ 正文生成 ─────────┤ 并行请求 DeepSeek
                            ▼
                  JSON解析、归一与兜底
                            │
             ┌──────────────┴──────────────┐
             ▼                             ▼
       内容编辑与局部重写             AI/本地四维质检
             │                             │
             └──────────────┬──────────────┘
                            ▼
                  Canvas封面导出与发布
```

技术栈：Next.js 16、React 19、TypeScript、Tailwind CSS 4、Framer Motion、Canvas API、DeepSeek API。

## 本地运行

```bash
npm install
cp .env.example .env.local
# 在 .env.local 填入 DEEPSEEK_API_KEY
npm run dev
```

浏览器打开 `http://localhost:3456`。没有 API Key 时仍可查看默认内容并体验本地质检。

## 验证

```bash
npm run lint
npm run build
```

## 项目结构

- `app/api/generate`：内容生成、局部重写、并行与失败重试
- `app/api/evaluate`：AI质检与本地规则降级
- `components/ContentGenerator.tsx`：Brief、生成、重写和评测交互
- `lib/prompt.ts`：生成与评测Prompt
- `lib/evaluation.ts`：评测解析、归一与本地评测
- `docs/PRODUCT-BRIEF.md`：产品问题、核心旅程和取舍
- `docs/EVALUATION.md`：评测口径、样本设计和迭代计划

## 当前边界

- 尚未接入小红书发布接口，不做自动发布；
- 不抓取歌词、艺人信息或平台内容，事实信息需创作者最终核对；
- 当前是作品集MVP，尚未用真实创作者样本验证留存与发布转化。
